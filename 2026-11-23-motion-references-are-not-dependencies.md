# Motion references are not dependencies

Lesson: A useful motion repository can belong in a reference catalog even when its runtime, framework, or license does not fit the current project. Treating every reference as an installable dependency creates unrelated requirements and can make an example illegal to reuse.

Rule: Link to the source and record its license, platform, primary patterns, and inspection date. Read source for techniques; compare native platform APIs before importing anything. Do not copy implementation code, add a package, or vendor an asset without confirming the project's requirements and the source's license.

Applies to: web, game, iOS, Android, video
