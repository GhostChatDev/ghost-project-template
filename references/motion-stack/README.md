# Motion stack

Optional references based on Florence’s [source post](https://x.com/flxrnc/status/2124608918899118512) and [The Fable 5.2 Motion Playbook](https://flxrnc.substack.com/p/the-fable-52-motion-playbook) (10 November 2026). These documents are not dependencies.

**Pipeline: idea → shape → motion → polish → export.**

1. Read `PRODUCT.md` and `DESIGN.md`.
2. Fill the matching brief in `briefs/` before animation.
3. Use `skills/motion-brief.md` to plan, then build one shot or system.
4. Have another pass use `skills/motion-qa.md` and `skills/taste-check.md`.
5. Record a reusable failure in `LESSONS.md`; stop after three failed looks.

The damping examples (1.0 lands dead, 0.8 hops once, 0.5 bounces) and the “plan on Medium, build on High” preference are attributed to Florence’s playbook, not measured in this repository. Use licenses current at the time of use. Nothing listed in `CATALOG.md` is installed here.
